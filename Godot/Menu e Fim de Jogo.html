Menu e fim de jogo

Seu jogo já tem a parte divertida. Falta uma entrada e uma saída: um menu com o botão Jogar e uma tela de fim de jogo com a pontuação. Tudo isso usa só nós de interface que a Godot já traz, então não precisa de imagem nem de som para testar.

Parte 1

Containers: a Godot posiciona por você

Nós de interface herdam de Control (os verdes). Se você colocar três Controls soltos dentro de um pai, todos nascem no mesmo canto e ficam empilhados. Em vez de arrastar cada botão no olho, use um Container: ele arruma os filhos sozinho. Troque o tipo abaixo e veja.

Parte 2

Trocar de cena e levar os pontos junto

Para ir de uma cena para outra existe uma linha só: get_tree().change_scene_to_file("res://level.tscn"). Mas tem uma pegadinha. Ao trocar, a cena antiga é apagada da memória, junto com as variáveis dela. O pontos do Level deixa de existir antes de a tela de fim de jogo abrir.

A solução simples é um Autoload: um script que a Godot carrega no começo e mantém vivo durante todo o jogo, acessível de qualquer cena pelo nome. Jogue uma rodada abaixo com a opção ligada e depois desligada.

    jogo.gd (registrado como Autoload com o nome Jogo)

    extends Node

var pontos := 0
var recorde := 0
    Parte 3

    Fazendo no seu projeto

    Seis passos. Marque cada um quando terminar.

    1. Crie a cena Menu

      Nova cena com a raiz Control, renomeada para Menu. Monte esta árvore:

      • Menu Control
        • CenterContainer
          • VBoxContainer
            • Titulo Label
            • Jogar Button
            • Sair Button

      No Inspetor, preencha o campo Text de cada Label e Button. Selecione a raiz Menu e, em Layout → Anchors Preset, escolha Full Rect. Faça o mesmo no CenterContainer. Sem isso, o menu fica espremido no canto.

    2. Script do menu

      Anexe um script na raiz Menu. Depois, para cada botão, aba Nó → dois cliques em pressed() → conectar ao Menu. A Godot cria as duas funções, e você só preenche:

      extends Control

func _on_jogar_pressed():
	get_tree().change_scene_to_file("res://level.tscn")

func _on_sair_pressed():
	get_tree().quit()

      O caminho dentro da string tem que ser o do seu arquivo. Clique com o botão direito no level.tscn e use Copiar caminho.

    3. Crie o Autoload

      Crie um script jogo.gd (pode ser pelo painel de arquivos, botão direito → Novo → Script, herdando de Node):

      extends Node

var pontos := 0
var recorde := 0

      Depois, em Projeto → Configurações do Projeto → Globais → Autoload, escolha o arquivo jogo.gd, deixe o nome como Jogo e clique em Adicionar. O nome é o que você vai escrever no código, com a mesma maiúscula.

    4. Crie a cena FimDeJogo

      Mesma ideia do menu, com esta árvore, também com Full Rect na raiz e no CenterContainer:

      • FimDeJogo Control
        • CenterContainer
          • VBoxContainer
            • Titulo Label ("Fim de jogo")
            • Pontos Label
            • Recorde Label
            • DeNovo Button
            • VoltarMenu Button

      Anexe o script na raiz, salve a cena como fim_de_jogo.tscn e conecte o pressed() dos dois botões:

      extends Control

@onready var pontos_label = $CenterContainer/VBoxContainer/Pontos
@onready var recorde_label = $CenterContainer/VBoxContainer/Recorde

func _ready():
	Jogo.recorde = max(Jogo.recorde, Jogo.pontos)
	pontos_label.text = "Pontos: %d" % Jogo.pontos
	recorde_label.text = "Recorde: %d" % Jogo.recorde

func _on_de_novo_pressed():
	get_tree().change_scene_to_file("res://level.tscn")

func _on_voltar_menu_pressed():
	get_tree().change_scene_to_file("res://menu.tscn")

      Dica para encurtar os caminhos: clique com o botão direito em um nó e escolha Acessar como nome único. Aí você escreve %Pontos em vez do caminho inteiro.

    5. Termine o jogo pelo Level

      No level.gd, na função que roda quando o tempo de 30 segundos acaba, guarde os pontos no Autoload e troque de cena:

      func _terminar():
	Jogo.pontos = pontos
	get_tree().change_scene_to_file("res://fim_de_jogo.tscn")

      Chame _terminar() de dentro do timeout do seu Timer de 30 s. A ordem importa: primeiro guarda, depois troca.

    6. Defina a cena principal e teste

      Clique com o botão direito em menu.tscn e escolha Definir como cena principal. Agora, com F5, o jogo abre no menu. Jogue até o tempo acabar: a tela de fim deve mostrar os pontos e o recorde. Jogue de novo, faça menos pontos, e o recorde deve continuar o mesmo.

      O recorde vale só enquanto o jogo está aberto, porque está na memória. Salvar em arquivo é um tema de uma aula futura.

    Para praticar

    Desafios

    • Mostre Recorde: N também no menu. Dica: o _ready() do menu pode ler Jogo.recorde.
    • Escreva "Novo recorde!" na tela de fim quando Jogo.pontos for maior que o recorde antes da linha do max.
    • Faça o inimigo emitir um sinal acertou, e o Level escutar e chamar _terminar(). Mesmo padrão da moeda, agora com o fim de jogo no lugar dos pontos.
    • Coloque um Label no Level mostrando o tempo que falta, lendo $Timer.time_left dentro do _process.

    Quando terminar, ou travar, me diga. Se quiser, o próximo assunto pode ser física de plataforma (gravidade e pulo, que também dá para testar só com formas do próprio editor), ou salvar o recorde em arquivo.
