Várias moedas

Com uma moeda, um @onready resolve. Com dez, não. Esta aula mostra como ligar todas de uma vez com grupos e um loop, e como gerar moedas novas por código com um Timer, que é a base de qualquer jogo de coletar coisas.

Parte 1

Grupos e loop: ligar todas de uma vez

Um grupo é uma etiqueta que você coloca em vários nós. Depois, get_tree().get_nodes_in_group("moedas") devolve todos eles em uma lista, e um for, igual ao do Python, passa por cada um. Experimente: tire uma moeda do grupo, rode o _ready() e tente coletar.

Cena Level: moedas

Pontos0

    moeda.gd

    extends Area2D

signal coletada(valor)

func _ready():
	add_to_group("moedas")

    level.gd

    func _ready():
	for moeda in get_tree().get_nodes_in_group("moedas"):
		moeda.coletada.connect(_on_moeda_coletada)

    Em vez do add_to_group no script, você pode marcar o grupo no editor: selecione o nó, aba Nó, seção Grupos. Em uma cena que é instanciada, vale a pena fazer isso na cena Moeda, para toda cópia já nascer no grupo.

    Parte 2

    Gerar moedas por código com um Timer

    Em vez de colocar as moedas à mão no editor, o Level cria uma nova a cada intervalo. O Timer é um nó que emite o sinal timeout de tempos em tempos, o mesmo mecanismo da aula de sinais. A cada timeout, o Level instancia a cena Moeda numa posição aleatória e liga o coletada dela.

    4. 
        
        
      Escreva o level.gd
      
        
      
          
      Substitua o conteúdo pelo código abaixo. A função _on_timer_timeout é a que a Godot criou no passo anterior; só preencha o corpo dela.
      
          
      

      extends Node2D

var pontos := 0
var moeda_cena := preload("res://moeda.tscn")

@onready var label = $HUD/Pontos

func _on_timer_timeout():
	if get_tree().get_nodes_in_group("moedas").size() >= 6:
		return
	var tela := get_viewport_rect().size
	var moeda = moeda_cena.instantiate()
	moeda.position = Vector2(randf_range(40, tela.x - 40), randf_range(40, tela.y - 40))
	moeda.coletada.connect(_on_moeda_coletada)
	add_child(moeda)

func _on_moeda_coletada(valor):
	pontos += valor
	label.text = "Pontos: %d" % pontos
      
          
      O moeda.coletada.connect(...) acontece antes do add_child, para a moeda já nascer ligada. O limite de 6 conta quantas moedas existem no grupo.
