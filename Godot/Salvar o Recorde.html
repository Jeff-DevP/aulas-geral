Salvar o recorde

O recorde que você guardou no Autoload some quando o jogo fecha, porque ele só existe na memória. Para ele sobreviver, é preciso gravá-lo em um arquivo e lê-lo de volta na próxima vez que o jogo abrir. É a mesma ideia de salvar um arquivo no Python, com algumas regras próprias da Godot.

Parte 1

Onde gravar: res:// ou user://

A Godot tem dois "lugares" para caminhos. O res:// é a pasta do seu projeto: ótima para ler cenas e scripts, mas somente leitura no jogo já exportado. O user:// é uma pasta de dados do jogador, criada para você gravar o que quiser. Salvamentos sempre vão em user://.

res:// (o projeto, só para ler)

  • menu.tscn
  • level.tscn
  • jogo.gd

user:// (dados do jogador, pode gravar)

  • save.cfg criado pelo jogo

Para ver a pasta real no seu computador, use no editor Projeto → Abrir pasta de dados do usuário. Por padrão ela fica em:

Windows%APPDATA%\Godot\app_userdata\NomeDoProjeto
Linux~/.local/share/godot/app_userdata/NomeDoProjeto
macOS~/Library/Application Support/Godot/app_userdata/NomeDoProjeto
Parte 2

Memória e disco, lado a lado

Jogue algumas rodadas e depois feche e reabra o jogo. Com as duas opções ligadas, o recorde volta. Desligue uma delas e veja o que acontece: cada opção é uma parte do código que você vai escrever.

Memória: Jogo.recorde0jogo aberto
Disco: user://save.cfg

        

        

        

          
          
          
        

        

          
          
        

        
    
      
    
      
    
        
    jogo.gd (o Autoload da aula 8, agora completo)
    
        
    extends Node

const ARQUIVO := "user://save.cfg"

var pontos := 0
var recorde := 0

func _ready():
	carregar()

func salvar():
	var cfg := ConfigFile.new()
	cfg.set_value("jogo", "recorde", recorde)
	cfg.save(ARQUIVO)

func carregar():
	var cfg := ConfigFile.new()
	if cfg.load(ARQUIVO) == OK:
		recorde = cfg.get_value("jogo", "recorde", 0)
    
        
    O ConfigFile grava um texto no formato que você vê ao lado: seção entre colchetes e chave=valor. Na primeira vez que o jogo roda, o arquivo ainda não existe, o load devolve um erro, e o recorde continua em 0.
    
      
    
    
    
  
    

  
  
    
    
    
      Parte 3
      
    Outra forma: JSON com FileAccess
    
      
    Para guardar poucos valores, o ConfigFile basta. Quando o save crescer (inventário, lista de fases concluídas), o JSON costuma ser mais prático, e você já o conhece do Python.
    
    
    
    
    func salvar():
	var arquivo := FileAccess.open(ARQUIVO, FileAccess.WRITE)
	arquivo.store_string(JSON.stringify({"recorde": recorde}))

func carregar():
	if not FileAccess.file_exists(ARQUIVO):
		return
	var arquivo := FileAccess.open(ARQUIVO, FileAccess.READ)
	var dados = JSON.parse_string(arquivo.get_as_text())
	if dados is Dictionary:
		recorde = int(dados.get("recorde", 0))

    1. 
        
        
      Complete o jogo.gd
      
        
      
          
      Substitua o conteúdo do script do seu Autoload pelo código abaixo. Ele mantém pontos e recorde e ganha duas funções.
      
          
      

      extends Node

const ARQUIVO := "user://save.cfg"

var pontos := 0
var recorde := 0

func _ready():
	carregar()

func salvar():
	var cfg := ConfigFile.new()
	cfg.set_value("jogo", "recorde", recorde)
	cfg.save(ARQUIVO)

func carregar():
	var cfg := ConfigFile.new()
	if cfg.load(ARQUIVO) == OK:
		recorde = cfg.get_value("jogo", "recorde", 0)
      
        
      
      
      2. 
      
    2. 
        
        
      Salve só quando bater o recorde
      
        
      
          
      No fim_de_jogo.gd, troque a linha do max por uma checagem, que também deixa pronto o "Novo recorde!" do desafio da aula anterior:
      
          
      

      var novo_recorde := false

func _ready():
	if Jogo.pontos > Jogo.recorde:
		Jogo.recorde = Jogo.pontos
		Jogo.salvar()
		novo_recorde = true
	pontos_label.text = "Pontos: %d" % Jogo.pontos
	recorde_label.text = "Recorde: %d" % Jogo.recorde
	if novo_recorde:
		recorde_label.text += "  Novo recorde!"
      
          
      Se você já fez o "Novo recorde!" do seu jeito, mantenha o seu e só acrescente Jogo.salvar() dentro do if.
      
        
      
      
      3. 
      
    3. 
        
        
      Teste fechando o jogo de verdade
      
        
      
          
      Rode com F5, jogue até o fim e bata um recorde. Feche a janela do jogo, rode de novo e olhe a tela de fim (ou o menu, se você fez aquele desafio). O recorde deve ter voltado.
      
        
      
      
      4. 
      
    4. 
        
        
      Espie o arquivo
      
        
      
          
      Em Projeto → Abrir pasta de dados do usuário, procure o save.cfg e abra em um editor de texto. Você deve ver algo como recorde=25. Apague o arquivo e rode o jogo: o recorde volta a zero.

    5. 
        
        
      Desafios
      
        
      
          
        
            
      • Mostre o recorde no menu, lendo Jogo.recorde no _ready() dele. Como o Autoload carrega antes da cena principal, o valor já estará lá.
        • 
            
      • Guarde um segundo valor no mesmo arquivo, como o maior número de moedas coletadas em uma rodada.
        • 
            
      • Faça um botão Zerar recorde no menu que apaga o arquivo com DirAccess.remove_absolute(Jogo.ARQUIVO) e zera Jogo.recorde.
